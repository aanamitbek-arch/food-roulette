# 🍽️ Food Roulette 
Food Roulette — это веб-приложение, которое помогает пользователю выбрать, где поесть, с помощью игровой рулетки.

## 🚀 Features
- 🎲 Случайный выбор еды
- 📍 Поиск ресторанов рядом (геолокация)
- 📜 История выборов
- 🎨 Красивый UI (Tailwind)

## 🛠️ Technologies
- HTML
- CSS (Tailwind)
- JavaScript
- Overpass API

## ▶️ How to run
Просто открой `index.html` в браузере.
